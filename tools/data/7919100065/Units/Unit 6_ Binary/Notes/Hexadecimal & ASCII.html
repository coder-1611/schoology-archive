Useful Python Functions

  • ord(c) - returns int ASCII value of character c
  • chr(i) - returns character at ASCII value i
  • bin(i) - returns str of int i in binary notation
  • hex(i) - returns str of int i in hexadecimal notation
  • int(s, b) - returns decimal int of string s in base b
