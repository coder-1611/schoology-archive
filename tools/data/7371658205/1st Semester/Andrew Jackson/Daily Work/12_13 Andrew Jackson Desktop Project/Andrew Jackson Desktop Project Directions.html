The student will create a desktop scene that could belong to Andrew Jackson. It must include the following items:

  1. Name Plate / Business Card (some way to identify the desk as belonging to Andrew Jackson)

  2. 5 separate journal entries (5 sentences for each entry)

  3. Picture of someone relating to Andrew Jackson’s presidency - must include a short description explaining the importance of the item. 

  4. To-Do List with 5 items 

  5. 1 meaningful object or memento from childhood to his Presidency- must include a short description explaining the importance of the item (NO PICTURE OF RACHEL). 

  6. A note to Jackson from someone else (10 sentences)
